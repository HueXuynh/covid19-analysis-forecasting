# Phân tích và dự báo xu hướng dịch COVID-19

## 1. Giới thiệu

Dự án thực hiện phân tích dữ liệu COVID-19 khu vực Châu Á
nhằm tìm hiểu xu hướng dịch bệnh và thử nghiệm các mô hình
dự báo ngắn hạn.

## 2. Mục tiêu

- Thu thập và làm sạch dữ liệu COVID-19.
- Phân tích xu hướng dữ liệu.
- Thử nghiệm các mô hình dự báo.
- So sánh kết quả giữa các mô hình.

## 3. Công cụ sử dụng

- Python
- Google BigQuery
- Pandas
- NumPy
- Matplotlib
- XGBoost
- LightGBM
- LSTM

## 4. Quy trình thực hiện

1. Thu thập dữ liệu
2. Làm sạch và tiền xử lý
3. Phân tích dữ liệu
4. Xây dựng mô hình
5. Đánh giá và so sánh kết quả
6. Trực quan hóa kết quả

## 5. Mô hình

Dự án thử nghiệm ba mô hình:

- XGBoost
- LSTM
- LightGBM

## 6. Kết quả

Các mô hình được đánh giá và so sánh dựa trên
các chỉ số đánh giá phù hợp với bài toán dự báo.

## 7. Cấu trúc thư mục

- `notebooks/`: Notebook phân tích và xây dựng mô hình.
- `results/`: Kết quả và biểu đồ.
- `data/`: Thông tin về dữ liệu sử dụng.
